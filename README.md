💰 Expenses Tracker Web Application

A full-stack web application to manage, track, and analyze personal expenses with an intuitive and responsive UI.

🚀 Features

🔐 Authentication – Secure login and signup with Supabase

✍️ Expense Management – Add, edit, delete, and categorize expenses

📊 Analytics Dashboard – Interactive charts with React Chart.js for spending insights

🗂️ Filtering & Sorting – View expenses by category, date, or amount

⚡ Real-Time Updates – Data synced instantly with Supabase

🌐 Responsive UI – Styled with Tailwind CSS and custom CSS

🚀 Deployment – Hosted on Netlify with continuous deployment

🛠️ Tech Stack

Frontend: React (TypeScript), React Router v7, Tailwind CSS, CSS, React Icons

State Management: Zustand

Backend & Database: Supabase (Auth + Postgres)

Data Visualization: React Chart.js

Deployment: Netlify
